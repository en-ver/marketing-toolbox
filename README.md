# marketing-toolbox

Command-line tools for the official Google APIs:

- `ga4datactl` — Google Analytics Data API v1beta
- `ga4adminctl` — Google Analytics Admin API v1beta
- `gtmctl` — Google Tag Manager API v2

## Features

- Query Google Analytics 4 reports with `ga4datactl`.
- Manage Google Analytics properties and accounts with `ga4adminctl`.
- Read and manage Google Tag Manager accounts, containers, tags, and versions with `gtmctl`.
- Inspect supported API requests with locally derived schemas.
- Control writes with explicit apply flags and added acknowledgements for sensitive actions.
- Store native OAuth credentials in the operating system keyring, or use externally managed Google credentials.

See the [official user documentation](https://marketing-toolbox.org/) for guides to [installation](https://marketing-toolbox.org/install/), [authentication](https://marketing-toolbox.org/auth/), [GA4 Data](https://marketing-toolbox.org/tools/ga4-data/), [GA4 Admin](https://marketing-toolbox.org/tools/ga4-admin/), and [Tag Manager](https://marketing-toolbox.org/tools/tag-manager/).
